# RSystem
项目采用 C/S 架构，主要实现主机对客户机的设备信息采集，具备 文件浏览与传输、锁定与解锁、状态管理等功能，系统使用 MFC 框架开发；
编译环境
1、编译工具：vs2019
2、编译语言：C/C++
3、操作系统：Windows10
4、辅助工具：git，StarUML
5、网络协议：TCP/IP
6、初步设计模式：客户端-服务端（C/S）模式
7、后期设计模式：一对多模式、客户端mvc架构

服务端

2、创建服务端套接字 socket()
3、初始化服务端信息 sockaddr_in 结构体
4、绑定套接字 bind()
5、监听listen()
6、连接accept()

8、数据处理
